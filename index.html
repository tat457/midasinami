職場体験・面接の「身だしなみ」即効チェックリスト

  • 髪型：おでこ・耳・襟足がすっきり。ボサボサでないか。
  • 服装：シワや汚れがなく、ボタンは留まっているか。
  • 足元：靴のかかとを踏んでいないか。汚れはないか。
  • 手元：爪は短く切ってあるか。（派手なネイル・汚れNG）
  • 姿勢：背筋をピシッと伸ばし、笑顔で明るく挨拶！

GitHub Pagesでの無料公開手順

  1. GitHubアカウントを作成してログインします。
  2. 「New Repository」からリポジトリ（例: manner-quiz）を作成します。
  3. このコード（index.html）をそのままアップロード（Add file -> Upload files）して Commit します。
  4. リポジトリの Settings > Pages を開き、Source を 「Deploy from a branch (main)」 に設定して Save を押します。
  5. 数分待つと、https://ユーザー名.github.io/manner-quiz/ のURLが発行され、誰でも遊べるようになります！
